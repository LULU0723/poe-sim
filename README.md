# Path of Exile 3.29 創生之樹｜策略最佳化模擬器 (poe-sim)

針對 Path of Exile 3.29 **創生之樹（Genesis Tree）** 機制的純前端規劃工具。依照 16 點上限規劃路線、模擬詞綴權重，並用暴力搜尋演算法找出評分最高的配置。

> **3.29 資料狀態：** 已套用裝備分支 16 點上限、額外裝備小天賦 50% → 25%，以及指定詞綴類型大天賦 500% → 300%。官方未公開「內建詞綴階級評分」、「高階基底傾向」與「內建額外裝備機率」的精確新數值，因此目前不對這三項隱藏參數進行推測。

> 適用對象：想拚特定詞綴組合、不想盲目試錯天賦點的玩家。

---

## ✨ 功能特色

- **🗺️ 雙視圖天賦樹**
  - 視覺地圖模式：依照原圖座標排列節點，可縮放（50%–300%）
  - 結構清單模式：依父子關係階層展開，方便看路徑
  - 座標校準模式：拖曳節點微調位置，自動存到 localStorage

- **🧮 即時機率計算**
  - 根據已啟用節點的 `mods`（如 `+300% 抗性詞綴`、`-60% 防禦詞綴`）動態調整每條詞綴的權重
  - 前綴 / 後綴分開計算佔比
  - 標籤命中採加總方式（與遊戲內 increased/reduced 相同邏輯，待驗證）

- **🎯 三類詞綴標記**
  - `🎯 目標詞`：希望出現的詞綴（評分 +1000 × 機率）
  - `✅ 可接受`：次要詞綴（評分 +100 × 機率）
  - `❌ 不想要`：污染詞綴（評分 -1000 × 機率）

- **🪄 一鍵最佳化**
  - 暴力枚舉 A/B/C 棄絕系列 × L/M/N 奉獻系列 × D/E/F/K 功能節點偏好
  - 自動填滿剩餘點數（保留玩家手動點過的工具節點）
  - 結束後給出警告：目標詞機率偏低、點數不足無法納入偏好節點

- **📚 內建詞綴庫**
  9 個裝備類別 × 屬性子分類，共 30+ 套 PoEDB 權重預設：
  頭盔 / 胸甲 / 手套 / 鞋子 / 護身符 / 戒指 / 腰帶 / 盾牌（含力/敏/智/力敏/力智/敏智）/ 珠寶（赤紅/鈷藍/翠綠）

- **🧭 策略顧問**
  針對 6 種屬性底材（純力 / 純敏 / 純智 / 力敏 / 力智 / 敏智）推薦：
  - 💰 **防污染法**（CP）：低點數，切斷稀釋來源
  - 🔥 **極限機率**（Max）：高點數，雙向強化目標屬性

- **📂 個人預設庫**
  - 匯入單一 JSON 或批次匯入多個 JSON
  - 自動存到 localStorage，下次開啟即可載入
  - 支援匯出當前詞綴設定備份

## 📖 使用流程

1. **選裝備類型與屬性**（右上角下拉選單）
   例如：`🛡️ 盾牌` → `💪 純力 (護甲)`

2. **點「讀取詞綴與策略」**
   - 自動載入對應的詞綴庫
   - 自動切換天賦樹基底鎖定節點（如盾牌會自動點上 `G1`）
   - 顯示策略顧問面板（僅防具底材會顯示）

3. **標記目標詞綴**
   下拉選單把想要的詞綴改成 `🎯 目標詞`、不想要的改成 `❌ 不想要`

4. **（可選）設定功能節點偏好**
   D / E / F / K 四個工具節點，依需求選「不需要 / 普通 / 重要」

5. **點「最佳化」**
   等個 0.5–1 秒，演算法會自動排出最高評分的天賦組合

6. **檢視結果**
   - 看每條詞綴的當前機率
   - 看警告提示（機率過低、點數不足等）
   - 不滿意可手動微調節點、再次最佳化

## 📄 詞綴 JSON 格式

`public/presets/*.json` 採用陣列格式：

```json
[
  {
    "id": "1775723800001",
    "type": "prefix",
    "name": "# 最大生命",
    "tags": "生命",
    "baseWeight": 11000,
    "category": "neutral"
  }
]
```

| 欄位 | 說明 |
|------|------|
| `id` | 唯一識別碼（字串）|
| `type` | `prefix` 或 `suffix` |
| `name` | 詞綴名稱，`#` 代表數值佔位符 |
| `tags` | 用逗號或頓號分隔的標籤，例如 `元素、火焰、抗性` |
| `baseWeight` | 基礎權重（整數）|
| `category` | `neutral` / `target` / `acceptable` / `unwanted` |

**支援的標籤**（會被節點 `mods` 影響）：
`生命` `魔力` `防禦` `屬性` `抗性` `速度` `施法` `攻擊` `暴擊` `閃電` `冰冷` `火焰` `物理` `混沌`

為相容既有預設，計算時會自動正規化以下別名：`能力` → `屬性`、`法術` → `施法`、`攻擊速度` → `攻擊` + `速度`。

匯入個人預設時也接受包裝格式：
```json
{ "affixes": [ /* 同上 */ ] }
```

## 🧪 模擬依據與限制（重要）

本工具將資料分為「官方已確認」、「模型假設」與「目前未模擬」，避免把推測數值當成遊戲規則。

### 3.29 已確認並套用

- 裝備類創生之樹上限為 16 點。
- 額外裝備小天賦為 25%。
- 指定詞綴類型核心天賦為 +300%。
- 每個基底仍只能從自身可用的詞綴池抽取；基礎權重為 0 的詞綴不會因 +300% 而出現。

3.29 官方也確認裝備具有較低的內建詞綴階級評分、偏向較高階基底，以及較低的內建額外裝備機率，但沒有公布這三項的精確數值，因此目前不將它們加入公式。參考：[3.29 官方更新說明](https://www.pathofexile.com/forum/view-thread/3985332)。

### 模型假設（待實測）

1. **減益相加且可歸零**：同時命中「物理」與「攻擊」的詞綴，在 −60% 物理與 −60% 攻擊下採 `1 − 0.6 − 0.6 → 0`。若官方實際採獨立相乘，則應為 `1 × 0.4 × 0.4 = 0.16`。
2. **多標籤加成相加**：同時命中「火焰」與「抗性」的詞綴，在兩個 +300% 下採 `1 + 3 + 3 = 7 倍`。其他可能機制為相乘 16 倍，或只取最高值 4 倍。
3. **共用 PoEDB 權重表**：內建 JSON 的基礎權重參考一般物品詞綴權重，假設創生之樹沒有另外使用隱藏權重表。
4. **屬性需求基底初始權重相同**：策略顧問暫時假設純力、純敏、純智及複合底的初始權重相同，再套用 ×0.15／×4 節點。這項假設不包含官方已確認但未公布數值的「高階基底偏向」。

### 目前未模擬

- 內建詞綴階級降低、高階基底偏向、內建額外裝備機率。
- 赤紅／鈷藍／翠綠珠寶基底的掉落分布。
- 完整物品生成、同群組互斥、前後綴數量分配與多條目標詞的聯合出現機率。

面板百分比只代表「抽取一條前綴或後綴時，抽中該詞綴的相對機率」，不是最終成品出現該詞綴的完整機率。
