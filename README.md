# 創世之樹 策略最佳化模擬器 (poe-sim)

針對 Path of Exile **創世之樹（Genesis Tree）** 機制的純前端規劃工具。在 20 點上限內排出最佳天賦組合，即時計算每條詞綴在當前配置下的出現機率，並用暴力搜尋演算法替你找出評分最高的路徑。

> 適用對象：想拚特定詞綴組合、不想盲目試錯天賦點的玩家。

---

## ✨ 功能特色

- **🗺️ 雙視圖天賦樹**
  - 視覺地圖模式：依照原圖座標排列節點，可縮放（50%–300%）
  - 結構清單模式：依父子關係階層展開，方便看路徑
  - 座標校準模式：拖曳節點微調位置，自動存到 localStorage

- **🧮 即時機率計算**
  - 根據已啟用節點的 `mods`（如 `+500% 抗性詞綴`、`-60% 防禦詞綴`）動態調整每條詞綴的權重
  - 前綴 / 後綴分開計算佔比
  - 標籤命中採加總方式（與遊戲內 increased/reduced 相同邏輯，待驗證）

- **🎯 三類詞綴標記**
  - `🎯 目標詞`：希望出現的詞綴（評分 +1000 × 機率）
  - `✅ 可接受`：次要詞綴（評分 +100 × 機率）
  - `❌ 不想要`：污染詞綴（評分 -1000 × 機率）

- **🪄 一鍵最佳化**
  - 暴力枚舉 A/B/C 棄絕系列 × L/M/N 奉獻系列 × D/E/F/K 功能節點偏好
  - 自動填滿剩餘點數（保留玩家手動點過的工具節點）
  - 結束後給出警告：目標詞機率偏低、點數不足無法納入偏好節點

- **📚 內建詞綴庫**
  8 個裝備類別 × 屬性子分類，共 30+ 套官方數據預設：
  頭盔 / 胸甲 / 手套 / 鞋子 / 護身符 / 戒指 / 腰帶 / 盾牌（含力/敏/智/力敏/力智/敏智）/ 珠寶（赤紅/鈷藍/翠綠）

- **🧭 策略顧問**
  針對 6 種屬性底材（純力 / 純敏 / 純智 / 力敏 / 力智 / 敏智）推薦：
  - 💰 **防污染法**（CP）：低點數，切斷稀釋來源
  - 🔥 **極限機率**（Max）：高點數，雙向強化目標屬性

- **📂 個人預設庫**
  - 匯入單一 JSON 或批次匯入多個 JSON
  - 自動存到 localStorage，下次開啟即可載入
  - 支援匯出當前詞綴設定備份

## 📖 使用流程

1. **選裝備類型與屬性**（右上角下拉選單）
   例如：`🛡️ 盾牌` → `💪 純力 (護甲)`

2. **點「讀取詞綴與策略」**
   - 自動載入對應的詞綴庫
   - 自動切換天賦樹基底鎖定節點（如盾牌會自動點上 `G1`）
   - 顯示策略顧問面板（僅防具底材會顯示）

3. **標記目標詞綴**
   下拉選單把想要的詞綴改成 `🎯 目標詞`、不想要的改成 `❌ 不想要`

4. **（可選）設定功能節點偏好**
   D / E / F / K 四個工具節點，依需求選「不需要 / 普通 / 重要」

5. **點「最佳化」**
   等個 0.5–1 秒，演算法會自動排出最高評分的天賦組合

6. **檢視結果**
   - 看每條詞綴的當前機率
   - 看警告提示（機率過低、點數不足等）
   - 不滿意可手動微調節點、再次最佳化

## 📄 詞綴 JSON 格式

`public/presets/*.json` 採用陣列格式：

```json
[
  {
    "id": "1775723800001",
    "type": "prefix",
    "name": "# 最大生命",
    "tags": "生命",
    "baseWeight": 11000,
    "category": "neutral"
  }
]
```

| 欄位 | 說明 |
|------|------|
| `id` | 唯一識別碼（字串）|
| `type` | `prefix` 或 `suffix` |
| `name` | 詞綴名稱，`#` 代表數值佔位符 |
| `tags` | 用逗號或頓號分隔的標籤，例如 `元素、火焰、抗性` |
| `baseWeight` | 基礎權重（整數）|
| `category` | `neutral` / `target` / `acceptable` / `unwanted` |

**支援的標籤**（會被節點 `mods` 影響）：
`生命` `魔力` `防禦` `屬性` `抗性` `速度` `施法` `攻擊` `暴擊` `閃電` `冰冷` `火焰` `物理` `混沌` `力量` `敏捷` `智力`

匯入個人預設時也接受包裝格式：
```json
{ "affixes": [ /* 同上 */ ] }
```

## 📁 專案結構

```
poe-sim/
├── index.html
├── package.json
├── vite.config.js
├── public/
│   ├── favicon.svg
│   ├── icons.svg
│   └── presets/                # 內建詞綴庫
│       ├── helmet_str.json
│       ├── body_armour_dex.json
│       ├── shield_str.json
│       └── ...                 # 共 30+ 個檔案
└── src/
    ├── main.jsx                # 進入點
    ├── App.jsx                 # 所有邏輯（單檔，~1050 行）
    ├── index.css
    └── assets/
```

`App.jsx` 內三大常數：
- `BUILT_IN_PRESETS`（內建詞綴庫目錄）
- `BASE_STRATEGIES`（策略顧問推薦規則）
- `TREE_DATA`（天賦樹節點：座標、cost、mutex、mods）

## ⚠️ 注意事項

- 節點 `mods` 的計算邏輯（more 相乘 / increased 相加）目前依照 PoE 一般規則實作，標記為**待驗證**——實際遊戲行為若有差異，請以遊戲為準
- 視覺地圖會嘗試載入 `/tree.jpg` 作為背景圖（目前 repo 內未附），無圖時自動隱藏不影響功能
- 所有資料存在瀏覽器 localStorage，清快取會清掉個人預設庫與座標校準
